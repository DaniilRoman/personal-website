# Simple Analytics badge

## Intent and constraints
Keep the website eligible for Simple Analytics' free plan by showing a visible, linked official badge on every page. Keep it compact and preserve the existing analytics script and footer credits.

## Approaches
- Place the badge beside the existing footer credits: compact and consistent with the current layout. Selected by the user.
- Place the badge on a separate line below the credits: gives it more space but makes the footer taller.

## Implementation
Use the official badge code or an unchanged official badge image, linked to Simple Analytics. Add it to the shared Hugo footer and allow it to wrap naturally on smaller screens. Verify the generated pages contain the badge and that the site builds.
